# Aether Browser - ورتن دیاں شرطاں (مسودہ v0.1)

> جائزے ہیٹھ مسودہ۔ قانونی صلاح نئیں۔

1. **ایہ کی اے۔** Aether Browser (”Aether”) Mozilla Firefox تے
   مبنی مفت اوپن سورس ویب براؤزر اے۔ Aether تبدیلیاں دا سورس
   کوڈ ہر ریلیز نال شائع ہوندا اے۔

2. **لائسنس۔** Aether دا اپنا کوڈ Mozilla Public License 2.0
   ہیٹھ اے۔ Firefox حصے اپنے مول لائسنس رکھدے نیں (MPL-2.0
   تے مطابق)۔ تریجھی دھر حصے (uBlock Origin، فونٹ، 7-Zip حصے)
   اپنے رکھدے نیں؛ براؤزر وچ `about:license` ویکھو۔

3. **ٹریڈ مارک۔** ”Aether Browser” تے ایندا لوگو Aether منصوبے
   دے نیں۔ ”Firefox” تے Firefox لوگو Mozilla Foundation دے نیں۔
   Aether Mozilla نال جڑیا نئیں تے نہ ایندی حمایت یافتہ اے۔

4. **ڈیزائن توں ٹریکنگ نئیں۔** ٹیلیمیٹری، Sync، Firefox کھاتے،
   مطالعے تے کریش رپورٹاں اوس Firefox کوڈ توں ہٹائیاں گئیاں نیں
   جس تے Aether بنیا اے، صرف بند نئیں کیتیاں گئیاں۔ مردہ نشان
   رہ سکدے نیں جتھے براؤزر نوں چلن لئی چاہیدے نیں، پر او تہانوں
   ٹریک نئیں کردے تے جانکاری نئیں بھیجدے۔ کدیں خلاف ثبوت ملے
   تاں ہٹاون لئی Aether ذخیرے یا براؤزر مدد تے رپورٹ کرو۔
   براؤزر مقررہ اپڈیٹ سرور تے اپڈیٹ جانچدا اے تے منگ تے Mozilla
   توں بولی پیک لیندا اے؛ کوئی براؤزنگ ڈیٹا نئیں بھیجیا جاندا۔
   اختیاری خصوصیاتاں (جیویں شامل ایکسٹینشن) اپنیاں پالیسیاں
   مطابق اپنیاں خدمتاں نال رابطہ کر سکدیاں نیں۔

5. **اپڈیٹ۔** انسٹالر باقاعدہ اپڈیٹ جانچ چالو کردا اے۔ نظام
   مطابق آپے یا مڑ شروع تے انسٹال ہوندے نیں۔ سیٹنگاں وچ بند
   کر سکدے او۔

6. **نظام تبدیلیاں۔** تنصیب پروگرام فائلاں، شارٹ کٹ تے ان انسٹال
   اندراج لکھدی اے۔ ہور سافٹ ویئر نئیں بدلدی۔ ان انسٹال فائلاں
   ہٹاندا اے؛ پروفائل ڈیٹا رہندا اے، ہٹاونا نہ چنو تاں۔

7. **کوئی وارنٹی نئیں۔** سافٹ ویئر ”جیویں اے” دتا جاندا اے،
   قانون دی ودھ توں ودھ حد وچ کوئی وارنٹی توں بغیر۔ ایندے
   ورتوں توں نقصان لئی لکھاری کسے صورت ذمہ دار نئیں۔

8. **قبولیت۔** Aether Browser انسٹال کرکے تسیں ایہ شرطاں قبول
   کردے او۔ قبول نہ ہووے تاں انسٹال نہ کرو۔
