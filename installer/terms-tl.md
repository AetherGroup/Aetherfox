# Aether Browser - Mga Tuntunin sa Paggamit (DRAFT v0.1)

> Draft na sinusuri. Hindi payong legal.

1. **Ano ito.** Ang Aether Browser (”Aether”) ay isang libreng
   open source na web browser na batay sa Mozilla Firefox. Ang source
   code ng mga pagbabago ng Aether ay inilalathala sa bawat release.

2. **Lisensya.** Ang sariling code ng Aether ay nasa ilalim ng Mozilla
   Public License 2.0. Ang mga bahagi ng Firefox ay pinapanatili ang
   orihinal na lisensya (MPL-2.0 at katugma). Ang mga bahagi ng third
   party (uBlock Origin, mga font, 7-Zip stub) ay pinapanatili ang
   kanila; tingnan ang `about:license` sa browser.

3. **Mga tatak.** Ang ”Aether Browser” at logo nito ay pag-aari ng
   proyektong Aether. Ang ”Firefox” at logo ng Firefox ay pag-aari ng
   Mozilla Foundation. Ang Aether ay hindi kaakibat o suportado ng
   Mozilla.

4. **Walang pagsubaybay mula sa disenyo.** Ang telemetry, Sync,
   Firefox account, pag-aaral, at crash report ay tinanggal mula sa
   Firefox code na pinagbabasehan ng Aether, hindi lang pinatay. Maaaring
   may patay na bakas kung saan kailangan ng browser para gumana, pero
   hindi ka nila sinusubaybayan at hindi nagpapadala ng impormasyon.
   Kung makakita ka ng ebidensyang salungat, i-report sa Aether repo o
   suporta ng browser para matanggal. Sinusuri ng browser ang mga update
   sa nakatalagang server at nagda-download ng language pack mula sa
   Mozilla kapag kailangan; walang browsing data na ipinapadala. Ang mga
   opsyonal na feature (hal. kasamang extension) ay maaaring kumontak sa
   sariling serbisyo ayon sa patakaran nila.

5. **Mga update.** Binubuksan ng installer ang regular na pagsusuri ng
   update. Awtomatikong nag-i-install o sa restart depende sa system.
   Pwedeng patayin sa Settings.

6. **Mga pagbabago sa system.** Nagsusulat ang pag-install ng program
   file, shortcut, at uninstall entry. Hindi binabago ang ibang
   software. Binubura ng uninstall ang mga file; profile data ay
   pinapanatili malibang piliin mong burahin.

7. **Walang warranty.** Ibinibigay ang software ”nang apa adanya”,
   nang walang anumang warranty, sa pinakamalawak na pinapayagan ng
   batas. Ang mga may-akda sa anumang pangyayari ay hindi mananagot sa
   pinsala mula sa paggamit nito.

8. **Pagtanggap.** Sa pag-install ng Aether Browser tinatanggap mo ang
   mga tuntuning ito. Kung hindi mo tinatanggap, huwag mag-install.
