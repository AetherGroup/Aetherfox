# Aether transparency

1. All source code is public, under a copyleft-compatible license
   (MPL-2.0, same as upstream Firefox).
2. Readable history: one patch, one reason. No generic "bug fix" commits
   and no predatory contributor agreements.
3. Binaries are built only from public repositories, with the process
   published in CI.
4. No proprietary blobs: all machine code comes from public source. No
   bundled extensions: blocking is integrated natively since 150.
5. Signed, immutable releases, each with its `.sha256` and build log.
6. Zero traffic before consent. Services are opt-in and self-hostable,
   with the endpoint replaceable before any request is made.
7. No ads, no promos, no banners, no dark patterns. Anything inherited
   from Firefox that violates this is removed as soon as possible.
8. Legal documents versioned in git with full history.
