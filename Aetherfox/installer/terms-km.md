# Aetherfox - លក្ខខណ្ឌប្រើប្រាស់ (សេចក្តីព្រាង v0.1)

> សេចក្តីព្រាងកំពុងពិនិត្យ។ មិនមែនដំបូន្មានច្បាប់ទេ។

1. **តើនេះជាអ្វី។** Aetherfox (”Aether”) ជាកម្មវិធីរុករក
   បណ្ដាញឥតគិតថ្លៃប្រភពបើកចំហផ្អែកលើ Mozilla Firefox។
   កូដប្រភពនៃការផ្លាស់ប្តូរ Aether ត្រូវបានផ្សព្វផ្សាយរាល់កំណែ។

2. **អាជ្ញាប័ណ្ណ។** កូដផ្ទាល់របស់ Aether នៅក្រោម Mozilla Public
   License 2.0។ សមាសភាគ Firefox រក្សាអាជ្ញាប័ណ្ណដើម (MPL-2.0
   និងឆបគ្នា)។ សមាសភាគភាគីទីបី (uBlock Origin, ពុម្ពអក្សរ,
   7-Zip) រក្សារបស់ខ្លួន; មើល `about:license` ក្នុងកម្មវិធីរុករក។

3. **ម៉ាក។** ”Aetherfox” និងស្លាកសញ្ញារបស់វាជារបស់គម្រោង
   Aether។ ”Firefox” និងស្លាកសញ្ញា Firefox ជារបស់ Mozilla
   Foundation។ Aether មិនជាប់ពាក់ព័ន្ធ នឹង Mozilla
   ហើយមិនទទួលបានការគាំទ្រពី Mozilla ទេ។

4. **គ្មានការតាមដានតាមរចនា។** Telemetri, Sync, គណនី Firefox,
   ការសិក្សា និងរបាយការណ៍គាំងត្រូវបានលុបចេញពីកូដ Firefox
   ដែល Aether សាងសង់លើ មិនមែនគ្រាន់តែបិទទេ។
   ស្លាកស្នាមស្លាប់អាចនៅកន្លែងដែលកម្មវិធីរុករកត្រូវការដើម្បីដំណើរការ
   តែវាមិនតាមដានអ្នក ហើយមិនផ្ញើព័ត៌មានទេ។
   ប្រសិនបើអ្នកឃើញភស្តុតាងផ្ទុយ សូមរាយការណ៍តាមឃ្លាំង Aether
   ឬជំនួយកម្មវិធីរុករកដើម្បីលុបចេញ។
   កម្មវិធីរុករកពិនិត្យការធ្វើបច្ចុប្បន្នភាពលើម៉ាស៊ីនមេដែលបានកំណត់
   ហើយទាញយកកញ្ចប់ភាសាពី Mozilla តាមតម្រូវការ;
   មិនផ្ញើទិន្នន័យរុករកទេ។
   មុខងារជម្រើស (ឧ. ផ្នែកបន្ថែមភ្ជាប់មក) អាចទាក់ទងសេវាខ្លួន
   តាមគោលការណ៍របស់ខ្លួន។

5. **ការធ្វើបច្ចុប្បន្នភាព។** កម្មវិធីដំឡើងបើកការពិនិត្យ
   បច្ចុប្បន្នភាពទៀងទាត់។ ដំឡើងដោយស្វ័យប្រវត្តិ
   ឬពេលចាប់ផ្តើមឡើងវិញអាស្រ័យប្រព័ន្ធ។
   អាចបិទនៅក្នុងការកំណត់។

6. **ការផ្លាស់ប្តូរប្រព័ន្ធ។** ការដំឡើងសរសេរឯកសារកម្មវិធី
   ផ្លូវកាត់ និងធាតុលុបចេញ។ មិនផ្លាស់ប្តូរកម្មវិធីផ្សេង។
   ការលុបចេញលុបឯកសារ; ទិន្នន័យប្រវត្តិរូបនៅដដែល
   លើកលែងតែជ្រើសលុប។

7. **គ្មានការធានា។** កម្មវិធីផ្តល់ ”តាមដំណើរ”
   គ្មានការធានាណាមួយ ក្នុងកម្រិតអតិបរមាច្បាប់អនុញ្ញាត។
   អ្នកនិពន្ធក្នុងករណីណាក៏មិនទទួលខុសត្រូវការខូចខាត
   ពីការប្រើប្រាស់ទេ។

8. **ការទទួលយក។** ដំឡើង Aetherfox
   មានន័យទទួលយកលក្ខខណ្ឌទាំងនេះ។
   បើមិនទទួលទេ កុំដំឡើង។
