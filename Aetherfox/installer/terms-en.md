4. **No tracking by design.** Telemetry, Sync, Firefox Accounts,
   studies and crash reporting are deleted from the Firefox code
   Aether is built on, not just switched off. Dead traces may
   remain where the browser needs them to function, but they do
   not track you or transmit information. If you ever find
   evidence to the contrary, please report it through the Aether
   repository or browser support so it can be removed. The browser
   checks for updates against the configured update server and
   downloads language packs from Mozilla on demand; no browsing
   data is sent. Optional features (e.g. bundled extensions) may
   contact their own services per their policies.

5. **Updates.** The installer enables periodic update checks.
   Updates install automatically or on restart depending on your
   system setup. You can disable checks in Settings.

6. **System changes.** Installing writes program files, shortcuts
   and an uninstall entry. It does not modify other software.
   Uninstalling removes program files; your profile data is kept
   unless you choose to delete it.
