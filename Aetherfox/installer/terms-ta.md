# Aetherfox - பயன்பாட்டு விதிகள் (வரைவு v0.1)

> மதிப்பாய்வில் உள்ள வரைவு. சட்ட ஆலோசனை அல்ல.

1. **இது என்ன.** Aetherfox (”Aether”) Mozilla Firefox
   அடிப்படையிலான இலவச திறந்த மூல வலை உலாவி. Aether மாற்றங்களின்
   மூலக் குறியீடு ஒவ்வொரு வெளியீட்டுடனும் வெளியிடப்படுகிறது.

2. **உரிமம்.** Aether சொந்தக் குறியீடு Mozilla Public License 2.0
   இன் கீழ் உள்ளது. Firefox கூறுகள் தங்கள் அசல் உரிமங்களைத்
   தக்கவைக்கின்றன (MPL-2.0 மற்றும் இணக்கமான). மூன்றாம் தரப்பு
   கூறுகள் (uBlock Origin, எழுத்துருக்கள், 7-Zip பகுதிகள்)
   தங்களுடையதைத் தக்கவைக்கின்றன; உலாவியில் `about:license` பார்க்கவும்.

3. **வர்த்தக முத்திரைகள்.** ”Aetherfox” மற்றும் அதன் சின்னம்
   Aether திட்டத்திற்குச் சொந்தம். ”Firefox” மற்றும் Firefox சின்னம்
   Foundation க்குச் சொந்தம். Aether Mozilla உடன் தொடர்புடையதல்ல, அதன் ஆதரவும் இல்லை.
   தொடர்புடையதல்ல, அதன் ஆதரவும் இல்லை.

4. **வடிவமைப்பால் கண்காணிப்பு இல்லை.** தொலை அளவீடு, Sync, Firefox
   கணக்குகள், ஆய்வுகள் மற்றும் செயலிழப்பு அறிக்கைகள் Aether
   கட்டப்பட்ட Firefox குறியீட்டிலிருந்து நீக்கப்பட்டுள்ளன,
   வெறுமனே அணைக்கப்படவில்லை. உலாவி இயங்கத் தேவைப்படும் இடத்தில்
   மந்தக் குறிகள் இருக்கலாம், ஆனால் அவை உங்களைக் கண்காணிக்காது,
   தகவல் அனுப்பாது. எப்போதாவது எதிர் ஆதாரம் கண்டால், நீக்க
   Aether களஞ்சியம் அல்லது உலாவி ஆதரவு வழியாகப் புகாரளிக்கவும்.
   உலாவி உள்ளமைக்கப்பட்ட புதுப்பிப்பு சேவையகத்தில் புதுப்பிப்புகளைச்
   சரிபார்த்து, தேவைக்கேற்ப Mozilla இடமிருந்து மொழித் தொகுப்புகளைப்
   பெறுகிறது; உலாவல் தரவு அனுப்பப்படுவதில்லை. விருப்ப அம்சங்கள்
   (எ.கா. உள்ளடக்கிய நீட்டிப்புகள்) தங்கள் கொள்கைகளின்படி தங்கள்
   சேவைகளைத் தொடர்பு கொள்ளலாம்.

5. **புதுப்பிப்புகள்.** நிறுவி அவ்வப்போது புதுப்பிப்புச்
   சரிபார்ப்புகளை இயக்குகிறது. கணினியைப் பொறுத்து தானாக அல்லது
   மறுதொடக்கத்தில் நிறுவப்படும். அமைப்புகளில் அணைக்கலாம்.

6. **கணினி மாற்றங்கள்.** நிறுவல் நிரல் கோப்புகள், குறுக்குவழிகள்
   மற்றும் நிறுவல் நீக்கப் பதிவை எழுதுகிறது. வேறு மென்பொருளை
   மாற்றாது. நிறுவல் நீக்கம் கோப்புகளை நீக்கும்; சுயவிவரத் தரவு
   இருக்கும், நீக்கத் தேர்வு செய்யாவிட்டால்.

7. **உத்தரவாதம் இல்லை.** மென்பொருள் ”உள்ளபடியே” வழங்கப்படுகிறது,
   சட்டம் அனுமதிக்கும் அதிகபட்ச அளவில் எந்த உத்தரவாதமும் இன்றி.
   அதன் பயன்பாட்டால் ஏற்படும் சேதத்திற்கு ஆசிரியர்கள் எந்த
   நிலையிலும் பொறுப்பல்ல.

8. **ஏற்பு.** Aetherfox நிறுவுவதன் மூலம் இந்த விதிகளை
   ஏற்கிறீர்கள். ஏற்கவில்லை எனில் நிறுவ வேண்டாம்.
