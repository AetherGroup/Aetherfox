# Aetherfox - ข้อกำหนดการใช้งาน (ฉบับร่าง v0.1)

> ร่างอยู่ระหว่างการทบทวน ไม่ใช่คำแนะนำทางกฎหมาย

1. **คืออะไร** Aetherfox (”Aether”) คือเว็บเบราว์เซอร์ฟรี
   และโอเพนซอร์สที่สร้างบนพื้นฐานของ Mozilla Firefox
   ซอร์สโค้ดของการเปลี่ยนแปลงของ Aether จะเผยแพร่ทุกเวอร์ชัน

2. **ใบอนุญาต** โค้ดของ Aether เองอยู่ภายใต้ Mozilla Public License
   2.0 ส่วนประกอบของ Firefox ยังคงใช้ใบอนุญาตเดิม (MPL-2.0
   และที่เข้ากันได้) ส่วนประกอบของบุคคลที่สาม (uBlock Origin
   แบบอักษร และ stub ของ 7-Zip) ยังคงใช้ใบอนุญาตของตน
   ดู `about:license` ในเบราว์เซอร์

3. **เครื่องหมายการค้า** ”Aetherfox” และโลโก้เป็นของโครงการ
   Aether ”Firefox” และโลโก้ Firefox เป็นของ Mozilla Foundation
   Aether ไม่เกี่ยวข้องและไม่ได้รับการรับรองโดย Mozilla

4. **ไม่ติดตามโดยการออกแบบ** เทเลเมทรี Sync บัญชี Firefox
   การศึกษา และรายงานข้อขัดข้องถูกลบออกจากโค้ด Firefox
   ที่ Aether สร้างขึ้น ไม่ใช่แค่ปิดไว้
   ร่องรอยที่ไม่ทำงานอาจเหลืออยู่ในจุดที่เบราว์เซอร์ต้องใช้
   แต่จะไม่ติดตามคุณและไม่ส่งข้อมูลใดๆ
   หากพบหลักฐานที่ขัดแย้ง โปรดรายงานผ่านที่เก็บของ Aether
   หรือฝ่ายสนับสนุนของเบราว์เซอร์เพื่อนำออก
   เบราว์เซอร์จะตรวจอัปเดตกับเซิร์ฟเวอร์ที่ตั้งค่าไว้
   และดาวน์โหลดชุดภาษาจาก Mozilla เมื่อต้องการ
   โดยไม่ส่งข้อมูลการท่องเว็บ
   ฟีเจอร์เสริม (เช่นส่วนขยายที่แถมมา) อาจติดต่อบริการของตน
   ตามนโยบายของตน

5. **อัปเดต** ตัวติดตั้งจะเปิดการตรวจอัปเดตเป็นระยะ
   โดยจะติดตั้งอัตโนมัติหรือเมื่อรีสตาร์ตตามระบบของคุณ
   สามารถปิดได้ในการตั้งค่า

6. **การเปลี่ยนแปลงระบบ** การติดตั้งจะเขียนไฟล์โปรแกรม
   ทางลัด และรายการถอนการติดตั้ง โดยไม่แก้ไขซอฟต์แวร์อื่น
   การถอนการติดตั้งจะลบไฟล์ออก
   ส่วนข้อมูลโปรไฟล์จะคงอยู่เว้นแต่คุณจะเลือกให้ลบ

7. **ไม่มีการรับประกัน** ซอฟต์แวร์นี้ให้มา ”ตามสภาพ”
   โดยไม่มีการรับประกันใดๆ ในขอบเขตสูงสุดที่กฎหมายอนุญาต
   ผู้เขียนจะไม่รับผิดต่อความเสียหายจากการใช้ไม่ว่ากรณีใด

8. **การยอมรับ** การติดตั้ง Aetherfox คือการยอมรับ
   ข้อกำหนดเหล่านี้ หากไม่ยอมรับอย่าติดตั้ง
